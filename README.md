## 📁 Projetos

### 🎨 Projeto CAD - CinExt
**Disciplina:** CIN0131 - Concepção de Artefatos Digitais

Uma plataforma hub de extensão do Centro de Informática onde discentes e docentes podem ter uma conta, postar ou demonstrar interesse em ações de extensão. O projeto foi desenvolvido com foco em **interface** e **prototipação** voltada para a experiência do usuário utilizando **Lovable**.

🔗 [Ver Protótipo](https://cinext.lovable.app)

### 🎮 Projeto IP - The Python's Trial
**Disciplina:** CIN0133 - Introdução à Programação

Um jogo 2D desenvolvido com **Pygame** onde o personagem principal enfrenta 3 inimigos intermediários e um chefe final. O jogo possui mecânicas de combate e coleta de itens.

🔗 [Ver Repositório](https://github.com/RogerioHenrique1403/IP_zelda)
